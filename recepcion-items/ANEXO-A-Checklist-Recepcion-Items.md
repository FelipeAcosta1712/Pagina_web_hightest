# Anexo A: Checklist Operativo de Recepción y Entrega de Ítems

Código relacionado: AFR-7.4.1 (FR-7.4.1)

Este checklist sirve para verificación rápida diaria o por caso. Marcar N/A cuando no aplique.

---

## 1. Inicio y autenticación
- [ ] Usuario autenticado y con permisos adecuados (crear/generar PDF)
- [ ] Selección de caso en progreso o nuevo formulario

## 2. Datos del cliente y generales
- [ ] Nº de Recepción seleccionado
- [ ] Fecha de Recepción registrada
- [ ] Fecha de Entrega (si aplica)
- [ ] Cliente seleccionado y NIT autocompletado
- [ ] "Facturar a Nombre de" definido (Mismo/Otro)
- [ ] "Informe a Nombre de" definido (Mismo/Otro)
- [ ] Nº de Remisión (NO REGISTRA u Otro)

## 3. Ítems del alcance
- [ ] Tipo de ensayo seleccionado (Ensayos Alcance)
- [ ] Filtros/búsqueda utilizados para ubicar ítems
- [ ] Cantidades diligenciadas por ítem (Recibida/Entregada/No Usado/Usado/Lavados)
- [ ] Observaciones por ítem (si aplica)
- [ ] Agregados artículos personalizados (si aplica)
- [ ] Vista previa de elementos guardados revisada

## 4. Lavado (si aplica)
- [ ] Pregunta de lavado respondida (Sí/No)
- [ ] Cantidad de elementos lavados (si Sí)
- [ ] Responsables del lavado (si Sí)

## 5. Totales y estado
- [ ] Totales de Recepción y Entrega verificados
- [ ] Estado general revisado (pendiente/en progreso/completo)

## 6. Observaciones
- [ ] Observaciones generales registradas

## 7. Firmas
- [ ] Firma cliente Recepción capturada y guardada
- [ ] Datos cliente Recepción (Nombre, Cargo, Cédula)
- [ ] Firma cliente Entrega capturada y guardada
- [ ] Datos cliente Entrega (Nombre, Cargo, Cédula)
- [ ] Representantes HIGH TEST seleccionados (Recepción y Entrega)
- [ ] Cargo autocompletado para HIGH TEST (Recepción y Entrega)

## 8. Validación y documentos
- [ ] Vista Previa generada y revisada
- [ ] PDF Recepción generado (si corresponde)
- [ ] PDF Completo generado
- [ ] Correo/Notificación enviado (si aplica)

## 9. Cierre
- [ ] Borrador guardado si el caso sigue abierto
- [ ] Caso archivado/entregado según política cuando esté completo
